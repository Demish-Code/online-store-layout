# 🛒 Адаптивный верстка интернет-магазина (Figma)

Адаптивная верстка веб-сайта интернет-магазина с каталогом товаров и карточками, разработанная строго по макету из Figma.

🚀 **Демо проекта (Deploy):** https://Demish-Code.github.io/online-store-layout/

## 🛠 Используемые технологии
- **HTML5** (семантическая верстка)
- **SCSS / SASS** (архитектура БЭМ, CSS-переменные, миксины)
- **Flexbox / CSS Grid** (адаптивные сетки)
- **Media Queries** (полная адаптивность под смартфонами, планшетами и ПК)
- **Git / GitHub Pages**

## ✨ Особенности проекта
- Чистая верстка по методологии БЭМ.
- Соответствие макету Figma (Pixel Perfect).
- Полная адаптивность и кроссбраузерность.
